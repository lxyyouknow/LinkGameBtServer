# BT 后端接入说明

最后修改日期：2026-09-09

## 变更记录
- 2026-09-09：按 lxy 要求保留现有优化版统计后台；online_time 计入 SDK 广告展示区间并改为15秒分段，服务端继续按 durationSeconds 求和、不重复加广告时长。新增客户端计时测试和服务端分段契约测试。补全服务端配置生成、部署模板和 migration 前的远端配置比对；云环境游客登录随测试账号开关关闭，只开放 TikTok 身份。后端需填写新环境并做首次部署/对账，不需修改统计表或原 migrations。
- 2026-09-08：复制为 LinkGameBt/LinkGameBtServer；新增配置隔离和发布锁，服务端 API/migrate 增加 BT 环境与 DSN 校验。接口、迁移、奖励和统计口径未改变。后端下一步需申请/接入独立新环境，完成原 migrations 与联调。详见新项目交接和配置填写说明。

## 当前接入状态（2026-09-08）
目前没有连接新旧云环境。新服务端只接受明确配置的 BT_PROJECT_KEY=pairpop-bt、相同 BT_ENV/APP_ENV 与 DSN/BT_DB_*；新库及用户名需 linkgame_bt_ 前缀。正式环境禁用测试账号登录。

数值 appId=1 继续沿用现有协议，依赖独立数据库隔离；API 路由、事件语义和广告 reward claim 幂等保持原样。历史接口详解在 docs/legacy；其中旧环境配置和发布命令不可执行。

必须用新的 TikTok Client Key/Secret 换票，并与客户端属于同一 App。运维与平台配置待 lxy 提供；当前 release 脚本的配置锁不等于联调已经通过。

## 在线时长新口径（2026-09-09）

见 [在线时长口径与验收](在线时长口径与验收.md)。其他事件、报表筛选、留存和 cohort 查询保持当前 LinkGame 优化版。只要继续 SUM(duration_seconds) 即得到含广告的总在线时长；禁止再加 ad_duration_ms。每个新分段仍使用唯一事件 ID，重复上传由原服务端幂等约束处理。保留1～300秒的协议兼容范围，新客户端正常主段为15秒，关闭/后台可能有1～14秒尾段。

## TikTok 身份入口（2026-09-09）

/v1/auth/guest 在测试账号开关关闭时返回 GUEST_LOGIN_DISABLED；正式/staging 的配置门禁强制关闭该开关。客户端正式包也没有游客/模拟平台兜底。此调整只隔离身份入口，不修改玩法、广告节点或奖励。

## 总览口径

`经营总览` 的日期范围筛选玩家首次出现日，即“所选日期新增玩家”。选中一批新增玩家后，
登录、进入游戏、在线时长和广告表现均统计这批玩家截至查询时的累计数据，不再把日期内活跃与
新增 cohort 混在同一组卡片中。

| 指标 | 计算口径 |
| --- | --- |
| 新增玩家 | `first_seen_date` 位于所选日期范围的玩家数 |
| 人均登录次数 | 新增玩家累计 `login_count` ÷ 新增玩家数 |
| 进入游戏成功率 | 累计至少一次 `enter_game` 的新增玩家数 ÷ 新增玩家数 |
| 进入主线率 | 累计至少一次普通关卡 `level_start` 的新增玩家数 ÷ 新增玩家数；包含新玩家自动直达第 1 关，显示在进入游戏成功率卡片小字中 |
| 人均在线时长 | 新增玩家累计 `online_duration` ÷ 新增玩家数 |
| D1/D3/D7 | 所选新增玩家中 `last_login_date >= first_seen_date + 1/3/7 天` 的人数 ÷ 所选新增玩家数；属于 HPGame 式累计留存 |
| 激励完播用户率 | 累计至少一次激励 `ad_success` 的新增玩家数 ÷ 新增玩家数 |
| 激励完播总数 | 新增玩家累计唯一激励广告尝试中的 `ad_success` 数 |
| 人均激励完播数 | 激励完播总数 ÷ 新增玩家数 |

经营指标卡趋势按 `first_seen_date` 分日，每个点继续表示该日新增 cohort 截至查询时的累计表现；
`每日趋势`、`广告总览` 和失败明细仍按服务端接收事件的自然日统计，方便观察每天波动及定位
具体版本问题。页面显式展示口径说明，不能把这几张表与新增 cohort 总览直接相减或互相代替。

## 广告事件解释

- `请求`：玩家触发广告入口并开始一次广告尝试。
- `成功展示`：平台 SDK 展示调用成功，不等于完播。
- `完播 / 正常关闭`：激励广告只认 SDK 完播结果；插屏按正常关闭结果统计。
- `提前关闭`：用户主动行为，单独显示，不归入 SDK 请求失败。
- `奖励到账`：激励完播后，服务端奖励 claim 成功；不能用完播代替真实到账。
- `结果未回传`：已成功展示，但筛选期内尚无完成或提前关闭终态，用于发现生命周期中断。

稳定业务位在页面中翻译为中文，包括提示道具、洗牌道具、火箭消除、通关奖励、每日礼包、
每日挑战追加次数、赛季补签和每三关插屏；底层 key 保持不变，避免影响现有事件与数据库。

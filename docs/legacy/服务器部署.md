用户级 systemd：

```bash
mkdir -p ~/.config/systemd/user
cp deploy/systemd/linkgame.service ~/.config/systemd/user/linkgame.service
systemctl --user daemon-reload
systemctl --user enable --now linkgame.service
loginctl enable-linger linkgame
```

Nginx/Cloudflare 由服务器管理员按 `deploy/nginx/linkgame.conf` 配置。若 Cloudflare Origin
Rule 直接转发到 23020，应由安全组限制来源，不能把 Go 端口长期开放给全网。

## 日常发布

本机复制 `.release.env.example` 为 `.release.env`，填写 SSH 私钥绝对路径。然后执行：

```bash
./一键发布服务端.command
```

Windows 10/11 安装 Go、Git、OpenSSH Client 后，可直接双击：

```text
一键发布服务端-Windows.bat
```

Windows 的 `.release.env` 中 `RELEASE_SSH_KEY` 填 Windows 绝对路径，例如
`C:\Users\你的用户名\.ssh\linkgame.key`。脚本会原生构建 Linux amd64、上传、执行 migration、
切换版本并检查健康接口，不依赖 WSL。Mac 与 Windows 脚本在新版本健康检查失败时都会尝试
把 `current` 软链回退到上一个版本。

脚本先跑测试、构建 Linux 包，再要求输入 `RELEASE`，之后上传、向前迁移、切换 `current`
软链、重启用户级 systemd 并检查服务器内部健康接口。

## 数据库跳板

工作机需要直连 RDS 时，使用 SSH 本地转发，不把 RDS 开放公网：

```bash
ssh -i /绝对路径/linkgame@18.183.189.2.key \
  -N -L 133123:database-2.c9ie8y6eckdj.ap-northeast-1.rds.amazonaws.com:3306 \
  linkgame@18.183.189.2
```

DBeaver 或命令行连接 `127.0.0.1:133123/linkgame`。密码只在本机数据库客户端保存。

# BT 广告触发配置与同步工具

最后修改日期：2026-09-14。由 LinkGame 新工具适配，当前本地完成，首次使用前须部署支持 GET /v1/ads/policy 的 BT 服务端。

策划编辑 `deploy/config/ad-policy.json` 的八项概率，单位为0～100整数；`_说明` 只供文件阅读，不下发客户端。已同步上游2026-09-14-2方案：进关魔药100%，其余七项0%。关闭自动播放不影响手动观看，当前客户端已移除通关插屏。

本项目根目录提供 `一键同步广告配置-Mac.command`、`一键同步广告配置-Windows.bat`。默认从本项目当前分支的远程跟踪分支获取最新已提交配置，不 pull、不覆盖本地代码。尚未提交配置时在终端执行 `go run ./cmd/sync-ad-policy --local`；加 `--dry-run` 只核对线上状态与差异。

工具先执行 BT 配置预检，SSH 只取本项目生成的 `.release.env`，远端必须是 `/home/linkgamebt/linkgame-bt-server/shared/ad-policy.json` 与 `linkgame-bt.service`。严格核对进程实际路径、文件哈希和 PID，加锁备份、原子替换，接口校验失败恢复旧文件；不重启服务。回执保存在 `output/ad-policy-sync/`。

客户端启动获取，运行中至少间隔60秒刷新；短暂离线复用最近5分钟有效配置，过期或非法则关闭自动播放。每个新弹窗只抽签一次，多入口共享单条素材，消费时仍用对应 placement/attempt 与服务端幂等奖励。

首次服务发布自动安装 shared/ad-policy.json；已有文件不会被整包发布覆盖。源码配置调整后用此工具热更新。工具保持 BT 的数据库/API/CDN/TikTok 及后台账号配置，不复制来源项目凭据。
